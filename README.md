📊 Contador de Palavras – Computação Paralela
📌 Sobre

Projeto para comparar o desempenho da contagem de palavras em arquivos .txt usando:

Execução Serial
Execução Paralela (CPU – threads)
Execução Paralela (GPU – OpenCL)
🚀 Tecnologias
Java
OpenCL (JOCL)
Python (gráficos)
CSV
⚙️ Funcionamento

O programa:

Lê um arquivo .txt
Busca uma palavra
Conta ocorrências
Mede o tempo de execução

Comparação entre:

Serial
Paralelo (2 a 10 threads)
GPU
▶️ Execução
git clone https://github.com/MiguelTacchi/contador-de-palavras---cmpt-paralela.git
Abrir na IDE (IntelliJ recomendado)
Adicionar jocl-2.0.4.jar
Rodar Main.java
📈 Resultados
Saída em: resultado.csv
Gerar gráficos:
python graficos.py

Computação paralela
Multithreading
GPU (OpenCL)
